GLOBEINTEL BANK — INSTALLABLE UI PREVIEW (PWA)
===============================================

This folder is a complete installable web app. It works on phones, tablets,
laptops and desktops through the browser. It is a sandbox UI preview:
sample data only, no real money movement, no provider connections.

WHAT IS INCLUDED
----------------
  index.html            The full app (all portals, photos embedded)
  manifest.webmanifest  Install metadata and app name
  sw.js                 Offline service worker
  icons/                App icons (192px and 512px)

INSTALL ON A PHONE
------------------
1. Upload this entire folder to any static HTTPS host, for example:
   - GitHub Pages
   - Netlify Drop
   - Vercel
   - Cloudflare Pages
   - Firebase Hosting
2. Open the hosted URL in Chrome, Edge, Safari or Firefox.
3. Phone:
   - Android Chrome: menu > "Install app" or "Add to Home screen".
   - iPhone Safari: Share > "Add to Home Screen".
4. The app now opens like a normal full-screen app from the home screen.

INSTALL ON A COMPUTER
---------------------
1. Open the hosted URL in Chrome or Edge.
2. Click the install icon in the address bar, or use
   menu > "Cast, save and share" > "Install page as app".
3. The app opens in its own window, outside the browser tab.

LOCAL PREVIEW ON THIS COMPUTER
------------------------------
From this folder, run any static web server, for example:

    npx serve .
    python -m http.server 8000

Then open http://localhost:8000 in the browser. Localhost is treated as a
secure origin, so the install option and offline caching work.

A phone on the same Wi-Fi can open http://YOUR-COMPUTER-IP:8000 for a preview,
but most mobile browsers only allow installation from HTTPS. Use a real HTTPS
host (or an HTTPS tunnel) for phone installation.

OFFLINE
-------
After the first successful load, the app shell, icons, photos and styles are
cached by the service worker. You can reopen it with no network connection.

IMPORTANT
---------
This is a demonstration interface. It does not connect to a bank, a ledger,
QuickBooks/Intuit, or any payment network. No credentials are real.
